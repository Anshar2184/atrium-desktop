# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, welcome newcomers, and keep discussions focused on the work. Harassment, personal attacks, discriminatory language and publishing others' private information are not acceptable.

To report a problem, contact the maintainers through a private GitHub security advisory or by opening an issue that asks for a private contact channel. Reports are handled confidentially.
