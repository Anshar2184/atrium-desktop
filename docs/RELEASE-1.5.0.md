# Atrium Desktop v1.5.0

继 v1.4.0 后发布其余已完成的设置界面与稳定性修复。

- 修复小组件画廊小幅缩窗后玻璃与内容错位，覆盖全部 14 种预览；画廊和桌面布局缩略图在等待新图期间使用同一视口缩放。
- 修复数字时钟在部分时间组合下出现省略号，原生小组件和设置预览均预留字形取整余量，全天字号保持稳定。
- 修复设置侧边栏切换时短暂变紫，颜色插值使用 RGB，保留原来的动画时长与颜色终点。
- 修复快速切换照片时旧解码结果或转场快照覆盖新画面，并处理图库位移动画及材质分界裁剪的兼容问题。
- 统一设置界面的圆角和控件样式，补齐对应设计与协议说明。
- 合并控制中心查询与写入的并发保护、投屏搜索生命周期修复，以及图标历史缓存清理与失败重试。

v1.4.0 的后台下载、用户选择重启安装、就绪验证及失败回滚继续保留。发布标题为 Atrium Desktop v1.5.0，附件为 Atrium-1.5.0-win-x64.zip 及其 .sha256 校验文件。

A08 的严格解析裁剪替代方案仍未完成，未作为本次发布的已解决问题；实现边界见 QUALITY-AUDIT-FIXES-2026-11-07.md。

发布验证：正式身份的原生 Release 与设置 Release 构建通过。发布源码下，画廊与布局预览完成 756 组几何检查（最大差异约 0.506 像素），全天时钟 11,520 次排版无截断；浅色、深色侧边栏过渡均无紫色采样；延迟照片解码后的 25 个最终图像缓冲一致且无残留快照。控制中心读取/写入、投屏生命周期、应用图标缓存，以及原生小组件 544 帧、窗口关闭 10 场景和气泡交互回归均通过。
