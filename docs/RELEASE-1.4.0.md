# Atrium Desktop v1.4.0

本次发布包含后台更新、小组件拉伸与任务栏窗口预览相关改进。

- 后台定期检查正式更新，使用 Windows BITS 下载；关闭设置中心后继续下载，完成后校验并准备更新包。安装由用户点击“重启并完成更新”触发。
- 更新安装等待核心及设置窗口就绪，失败时恢复旧包；下载状态损坏时保留恢复信息并报告错误。开发构建与正式安装的目录、自启动归属分别检查。
- 小组件拉伸时按实际尺寸裁剪内容，保留原有内容布局、动画和双侧握把；稳定宿主与复用缓冲减少尺寸变化时的错位，桌面模糊采样保持对齐。
- 修复悬停窗口预览的关闭按钮和中键关闭，及时移除已关闭或隐藏的窗口卡片；列表变化期间按下目标仍跟随原窗口。
- 名称气泡增加底部指针，出现和消失复用现有面板动画；快速切换、屏幕边缘定位与窗口预览交接保持原有交互。

发布标签：v1.4.0。标题：Atrium Desktop v1.4.0。
附件：Atrium-1.4.0-win-x64.zip 及同名 .sha256 校验文件，压缩包顶层为 Atrium 文件夹。

设置界面的照片切换、侧边栏颜色、数字时钟及画廊缩放等其余修改留待 v1.5.0。本次仅验证所列更新链路和组件回归，不宣称已解决全部审计问题。

发布验证：原生正式身份 Release 与设置 Release 发布通过；预览关闭 10 种场景、气泡快速切换与边缘锚点、8 类小组件四档缩放的 544 帧及 180 帧连续伸缩检查通过。玻璃 mip0–6 漂移为 0/255；关闭尖角时 91,720 像素与旧材质相同。独立更新演示包的成功、交换失败、核心失败、设置失败、就绪超时及回滚失败六种场景通过，未对正式安装故障注入。
